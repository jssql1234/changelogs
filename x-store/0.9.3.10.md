This release adds new TikTok fees and fixes issues with Post Order, WooCommerce orders, and Sync Stock.

<!-- truncate -->

## Updates

- **Order**:
  - Added new TikTok Hazmat Handling Fee, Hazmat Noncompliance Fee, Non Standard Dimension Fee, Non Standard Weight Fee, New Customer Growth Package Fee, Target Product Gmv Growth Package Fee, Store Gmv Growth Package Fee and Auto Post Shoppable Video Commission Fee

## Bug Fixes

- **Post Order**:
  - Fixed an incorrect refund `docAmt` calculation
  - Fixed fees with the same description being listed as separate rows instead of being grouped and summed

- **Order**:
  - Fixed a WooCommerce order detail unmarshalling error for values with the `Number` type

- **Stock**:
  - Fixed the Sync Stock table incorrectly displaying the Creation Date in the Code column
