This release adds stock, picking list, permission, and store management features, and improves transaction processing and API reliability across all supported platforms.

<!-- truncate -->

## Database

- Database upgraded to version **9**

## Features

- **Customization**:
  - Added picking list customization

- **Permission**:
  - Added edit permissions

- **Store**:
  - Added unlink store feature

## Updates

- **Stock**:
  - Stopped automatically creating store products for unmapped codes during alternative-code automatic mapping
  - Updated the Stock interface so that Location displays only mapped locations
  - Added pagination, filtering, and search to the Stock Detail interface

- **Store**:
  - Updated Direct Shop to retrieve the global ID

- **Permission**:
  - Changed the Picker and Packer permission strings

- **Settings**:
  - Changed the save logic, removed the settings table, and migrated settings to JSON

- **Transactions**:
  - Updated payout retrieval to use descending order
  - Changed product values from `float64` to `decimal`

- **Lazada**:
  - Changed transaction batch retrieval to use a three-month range

- **API Clients**:
  - Updated e-commerce API clients to check token expiry and refresh tokens before calling endpoints, while retaining token refresh after failed API calls

- **Shopify**:
  - Removed Shopify return processing from return creation
  - Used the latest transaction date as the payment date
  - Ran Sync Order calls triggered after Shopify actions in a goroutine

## Bug Fixes

- **Sync Stock**:
  - Fixed stock item synchronization logic for updating, inserting, and deleting UOMs, BOMs, barcodes, and alternative codes

- **TikTok Transactions**:
  - Fixed a transaction error by adding a new field

- **Shopee Transactions**:
  - Fixed an error involving zero-value adjustments

- **Lazada Transactions**:
  - Fixed transaction item descriptions being displayed as empty because of incorrect SKU mapping

- **WooCommerce**:
  - Fixed an unmarshalling error

- **Shopify**:
  - Fixed processed returns not refunding orders
