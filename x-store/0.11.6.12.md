This release displays connection response times, and improves Post Order retry handling and logging. It also ensures that remaining orders are marked as skipped when the posting process is terminated.

<!-- truncate -->

## Updates

- **Test Connection**:
  - Added the connection response time

- **Post Order**:
  - Added a 30-second delay before retrying a post request that returns an HTTP 500 error
  - Added logging for the posting speed of each batch

## Bug Fixes

- **Post Order**:
  - Fixed an issue where terminating the posting process failed to mark the remaining orders as skipped
