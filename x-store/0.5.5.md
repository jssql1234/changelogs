This release adds debugging and TikTok regional price validation, updates consumer version support, and fixes quantity, dashboard, store linking, transaction, and routing issues.

<!-- truncate -->

## Features

- **System**:
  - Added debug endpoints

- **TikTok**:
  - Added region-specific price limit validation when creating products

## Updates

- **Consumer**:
  - Added support for multiple versions

- **Authentication**:
  - Added a redirect from `/login` to `/central/login`

## Bug Fixes

- **Sync Quantity**:
  - Fixed failures when updating quantity logs during order synchronization

- **Dashboard**:
  - Fixed the dashboard not displaying all existing regions

- **WooCommerce**:
  - Fixed store linking failures caused by the backend not consuming the callback

- **TikTok Transactions**:
  - Fixed failures when saving `shopsku`

- **Routing**:
  - Updated route handling on spamming request by returning 404
