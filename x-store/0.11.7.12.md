This release introduces more flexible store code and stock mapping, new order and payment synchronization options, barcode-based and order-based stock picking, stock price management, Shopee product boosting, and CSV payment exports. It also streamlines mapping and stock management workflows, improves stock sync recovery, and enhances the default search field.

<!-- truncate -->

## Features

- **Store**:
  - The Map Code dialog now allows grouped stores to assign a different code to each store, except for the Location Code

- **Order**:
  - New orders can now be moved directly to the `To Ship` tab
  - Added a new order and payment sync mode: `Sync by Payment Date`
  - Stock Pick can now be started using either a Picking List barcode or an Order ID

- **Stock**:
  - Added price update functionality to Stock Details

- **Automap Dialog**:
  - Redesigned the Automap dialog with a table layout
  - Stock codes and UOMs can now be changed before mapping

- **Product**:
  - Added support for boosting Shopee products

- **Payment**:
  - Added the option to export payment data as a CSV file

- **Post Order**:
  - Disabled 5 cents rounding when invoice or credit note is created (requires SQL Account version 6.2026.1104.906 or later)

## Updates

- **Map Dialog**:
  - The Map dialog now shows unmapped products by default
  - The first unmapped product is now selected automatically
  - Added a copy button next to the stock code (SKU)

- **Stock**:
  - The last synced stock code is now saved in the progress tracker, allowing stock synchronization to resume from that code
  - Combined the Update Price and Update Quantity features into a single dialog
  - Moved the `Update Price & Quantity` and `Unmap Product` buttons to the `Actions` dropdown menu
  - Actions in Stock Details are now enabled only when a product is selected

- **UI**:
  - Improved the default search field

## Bug Fixes

- **Order**:
  - Fixed lazada raw transaction marshal error

- **Dashboard**:
  - Fixed an issue where the pie chart was not displayed when the chart was filtered by `Amount`
