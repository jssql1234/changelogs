This release fixes issues with Post Order, store linking, and the Map Product dialog, and improves automatic mapping by alternative code.

<!-- truncate -->

## Updates

- **Stock**:
  - Sync Stock and Sync Product now automatically map products to the SQL Account stock item’s base UOM when the alternative code is mapped correctly but the UOM is empty
  - Sync Stock and Sync Product now return a warning when automatic mapping by alternative code is skipped

## Bug Fixes

- **Post Order**:
  - Lazada wrong weight adjustment fee is now to be insert in CN document wehen it is received separately from settlement
  - Fixed date-time validation when generating documents

- **Store**:
  - Fixed recurring refresh failures for Shopee Direct Shop

- **Product**:
  - Fixed an issue where the product list failed to load when it contained more than 1,000 products
