This release improves manual order posting and fixes refund, document lookup, SKU mapping, and order ID issues.

<!-- truncate -->

## Updates

- **Post Order**:
  - Added a selected-order count when posting orders manually
  - Changed Post All to post orders without applying filters

## Bug Fixes

- **Post Order**:
  - Fixed SQL Account returning an `Operation Aborted` error when the refund `docAmt` was missing
  - Fixed `docNo` not being found when searching for existing Lazada documents
  - Fixed products being mapped using an incorrect SKU format from transactions
  - Fixed orders being posted with an incorrect order ID

- **Order**:
  - Fixed products being mapped using an incorrect SKU format from transactions
