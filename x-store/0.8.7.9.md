This release improves the Sync and Post Order interfaces, Shopee return processing, queue recovery, and automatic quantity synchronization.

<!-- truncate -->

## Updates

- **Post Order**:
  - Moved Post Order to Settings > Post Order and added a progress bar and an option to view failed orders

- **Sync Dialog**:
  - Changed sync results to display in a table

- **Database Upgrade**:
  - Improved the database upgrade and connection termination logic

- **Order**:
  - Displayed the latest transaction date before conversion so that it matches the date shown in SQL Account

- **Shopee**:
  - Increased the escrow synchronization range from 7 days to 15 days
  - Updated return detail retrieval to use the return ID provided by escrow

- **Queue**:
  - Updated the Redis queue to resume pending messages after a container restart

- **Webhook**:
  - Added automatic quantity synchronization when the setting is enabled

## Bug Fixes

- **Product**:
  - Fixed an index-out-of-range error when synchronizing Shopee product price information

- **Shopee Transactions**:
  - Fixed detailed return item amounts being replaced with the total return amount
  - Fixed a missing access token when fetching data

- **Transactions**:
  - Fixed items with a zero amount being excluded from transactions
