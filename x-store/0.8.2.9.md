This release adds company-level Post Order settings, stock management features, email verification, and multiple synchronization and transaction improvements.

<!-- truncate -->

## Features

- **User Profile**:
  - Added email verification when updating an email address

- **Post Order**:
  - Added a company-level setting that allows users to select manual posting or post all orders

- **Stock**:
  - Added delete stock items feature
  - Added Stock Group and Stock Control filters to Sync Stock

## Updates

- **Product**:
  - Added `CompareAtPrice` to Shopify product creation

- **TikTok Transactions**:
  - Changed transaction to save shipping cost breakdowns

- **Authentication**:
  - Added a Redis lock to prevent two service threads from refreshing tokens simultaneously

- **Post Order**:
  - Used the discounted price instead of the original price as the item unit price when posting invoices for orders without payments
  - Added more meaningful descriptions when posting invoices

- **Database**:
  - Reset the `SY_ROLE` auto-increment key after inserting the default roles

- **Shopify Transactions**:
  - Used presentment money instead of shop money to improve transaction detail accuracy

## Bug Fixes

- **Synchronization**:
  - Fixed product and order synchronization timeout issues

- **Product**:
  - Fixed the alternative code automatic mapping limit check
  - Fixed nullable field values returned by `GetItemDetails`

- **Shopee**:
  - Added the shipping date only when it was available

- **Stock**:
  - Fixed a blank page appearing when a stock detail URL was copied and opened in a new tab
