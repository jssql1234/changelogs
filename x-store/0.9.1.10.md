This release improves Post Order recovery, stock item validation, product management, Shopee integration, and database upgrade safety.

<!-- truncate -->

## Features

- **Stock**:
  - Added checks for mapped default, voucher, discount, shipping, and transaction codes before deleting a stock item

- **Post Order**:
  - Stored queued order statuses in the database instead of passing them as messages, allowing Post Order processing to resume after a server restart

## Updates

- **Product**:
  - Updated Shopee logistics channel handling

- **Database Upgrade**:
  - Changed the connection termination logic to prevent automatic database upgrades for safety

## Bug Fixes

- **Store**:
  - Fixed the Map Code dialog not displaying a warning when a code could not be found

- **Product**:
  - Fixed TikTok product creation failures
  - Fixed Shopee product update failures
  - Fixed product information not refreshing after an update
  - Fixed missing TikTok brand information when `No Brand` was selected
  - Fixed Shopee global access token refresh failures

- **Order**:
  - Fixed a Shopee escrow detail unmarshalling error caused by the tenure list (changed field type from object to object array)
