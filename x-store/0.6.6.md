This release adds support for posting historical invoices, improves authentication and store linking, and fixes product synchronization, automatic mapping, and transaction issues.

<!-- truncate -->

## Features

- **Post Order**:
  - Added support for posting historical invoices using `system_conversion_date`

- **Frontend**:
  - Added the current website version below the sidebar

## Updates

- **Order**:
  - Reduced the transaction retrieval range from 300 days to 30 days

- **Authentication**:
  - Increased the verified login duration from two minutes to 24 hours
  - Added a token refresh attempt after a `401 Unauthorized` response and updated the store status accordingly

- **Product**:
  - Standardized the `updateImage` key using the TikTok key format

- **Store**:
  - Added validation that returns an error when linking a Mart or Outlet shop
  - Changed the Shopify store linking and relinking paths

## Bug Fixes

- **Lazada**:
  - Fixed product synchronization failures caused by a `quantity` unmarshalling error

- **Automatic Mapping**:
  - Fixed failures when inserting large amounts of data
  - Used the base UOM when the alternative code UOM was empty
  - Prevented automatic mapping when the UOM was unknown

- **Transactions**:
  - Fixed incorrect transaction updates

- **Shopee**:
  - Fixed products not appearing in the Map Product dialog

- **TikTok**:
  - Fixed image upload failures when creating or updating products
  - Fixed category ID lookup failures when creating or updating products
