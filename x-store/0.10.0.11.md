This release improves order posting accuracy, tracks transaction synchronization times, and standardizes decimal handling across all models.

<!-- truncate -->

## Database

- Database upgraded to version **11**

## Updates

- **Post Order**:
  - Added tracking for order transaction synchronization times by using `TRANSACTION_UPDATED_AT` so orders can be marked as unposted more accurately

- **Models**:
  - Changed all models to use the `decimal` type for consistency

- **Order**:
  - Added the new Shopee Pay Per Sale Fee

## Bug Fixes

- **Post Order**:
  - Added a rounding adjustment during order posting to correct amount discrepancies caused by rounding
  - Fixed categorization of item in Invoice document or Credit Note document

- **Order**:
  - Fixed Shopee transaction comparison method
