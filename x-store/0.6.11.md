This release improves stock item automatic mapping and fixes store code mapping, order synchronization, cancellation, payout, and SKU formatting issues.

<!-- truncate -->

## Updates

- **Stock Item Automatic Mapping**:
  - Limited automatic mapping to 50 alternative codes per stock item

- **Order Synchronization**:
  - Increased the shipment provider field limit from 50 to 255 characters

## Bug Fixes

- **Store**:
  - Fixed the Map SQL Code dialog not displaying all location codes
  - Fixed selected codes disappearing from the Map SQL Code dialog
  - Fixed newly mapped codes not appearing after refreshing the Map SQL Code dialog

- **Order**:
  - Fixed invoices not being updated to Cancelled when their orders were cancelled
  - Fixed `shopsku` being formatted incorrectly when processing transactions
  - Fixed Shopee payout calculations
