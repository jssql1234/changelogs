This release fixes the DNS prefix used for WooCommerce stores and prevents incorrect location codes from being added during alternative-code automapping.

<!-- truncate -->

## Bug Fixes

- **DNS**:
  - Fixed an issue where WooCommerce store DNS used an incorrect prefix.

- **Alt Code Automapping**:
  - Fixed an issue that inserted incorrect location codes during automapping.
