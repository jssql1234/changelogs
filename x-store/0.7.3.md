This release adds new order posting, stock verification, product, monitoring, and notification capabilities, along with major integration and synchronization improvements.

<!-- truncate -->

## Features

- **Post Order**:
  - Added recalculation logic for incorrect calculations
  - Added dual posting modes (Post All, Post Selected)

- **Stock Pick**:
  - Added stock verification using SQL Account stock item barcodes

- **Repost Order**:
  - Added the latest transaction date to the Repost Order table

- **Picking List**:
  - Added seller SKUs to picking lists

- **Order**:
  - Added buyer notes to order details

- **Product**:
  - Added an option to select a size chart template when creating or updating products

## Updates

- **Shopify**:
  - Changed Shopify GraphQL model generation to use a library
  - Updated the Shopify API version to `2026-04`

- **Post Order**:
  - Used the shipped date when posting orders

- **Synchronization**:
  - Improved order and product synchronization performance by updating the message queue logic

- **Authentication**:
  - Changed the user refresh token TTL to six hours

## Bug Fixes

- **Store**:
  - Fixed store linking failures for multi-store accounts when using the Link Store button in the table

- **Shopee**:
  - Fixed Direct Shop product synchronization failures
