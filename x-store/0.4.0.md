This release adds product mapping and filtering capabilities, improves default code management and the interface, and fixes payment, product, and Shopee synchronization issues.

<!-- truncate -->

## Features

- **Filtering**:
  - Added an option to select all records matching the current filter

- **Product Mapping**:
  - Added automatic mapping
  - Limited product mapping to 50 products per stock item

- **System**:
  - Added a `404` page

## Updates

- **Map Code Dialog**:
  - Added remarks and an option to remove the default code

- **User Interface**:
  - Updated the interface and color scheme

- **Order**:
  - Removed the order date-range filter restriction

## Bug Fixes

- **Payment**:
  - Fixed the payment total display

- **Product**:
  - Fixed product creation and filtering issues

- **Shopee**:
  - Fixed order synchronization failures
