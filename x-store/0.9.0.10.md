This release upgrades the database to version 10, adds configurable SQL Account time zones, and improves order and transaction processing across TikTok, Lazada, and Shopee.

<!-- truncate -->

## Database

- Database upgraded to version **10**

## Features

- **Company Profile**:
  - Added an option to set the time zone used for SQL Account, with Asia/Kuala Lumpur as the default

## Updates

- **Order**:
  - Added handling for additional Lazada and Shopee webhooks
  - Changed the price used for TikTok pre-settlement processing from Original Price to Sale Price

## Bug Fixes

- **Transactions**:
  - Fixed transaction dates not being displayed according to the user's time zone

- **Post Order**:
  - Fixed orders not being posted according to the user's configured time zone

- **Connection**:
  - Improved Test Connection to return meaningful error messages

- **Shopee**:
  - Fixed incomplete raw order details

- **TikTok**:
  - Fixed a cancelled order transactions display error
