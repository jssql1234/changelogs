This release adds logging for order-posting speed and improves store linking by updating all information returned by each platform. It also fixes product update failures caused by out-of-range prices, Lazada order code parsing, and the payment search placeholder text.

<!-- truncate -->

## Updates

- **Post Order**:
  - Added logging to track order-posting speed.

- **Store**:
  - Updated store linking to refresh all information returned by each platform.

## Bug Fixes

- **Product**:
  - Fixed an issue that caused product updates to fail when a price was out of range.

- **Order**:
  - Fixed an issue when parsing Lazada order codes.

- **Payment**:
  - Fixed the payment search placeholder text.
