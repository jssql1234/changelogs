This release adds product previews and search filtering, improves frontend performance and interfaces, and fixes product and Shopee integration issues.

<!-- truncate -->

## Features

- **Product**:
  - Added product previews for Shopify and WooCommerce

- **Filtering**:
  - Added `search_field` for filtering orders and products

## Updates

- **Frontend**:
  - Improved frontend performance
  - Updated the Shopee Pack Order dialog
  - Updated the filter interface

- **System**:
  - Updated the `brand_cache.sh` script

## Bug Fixes

- **Product**:
  - Fixed Shopify and WooCommerce product creation issues

- **Shopee**:
  - Fixed return webhook processing
  - Fixed product price update errors
