This release adds Microsoft login, Shopee Direct Shop linking, expanded order posting and product controls, and several synchronization and stock improvements.

<!-- truncate -->

## Database

- Database upgraded to version **5**

## Features

- **Authentication**:
  - Added Microsoft personal account login

- **Order**:
  - Added Shipping Provider, Region, and Postal Code to the Order Summary table

- **Post Order**
  - Added support for posting BOM items and historical invoices
  - Added posting statuses to the table for improved clarity

- **WooCommerce**:
  - Added an option to control stock management when editing products

- **Shopee**:
  - Added Direct Shop linking

## Updates

- **Shopify**:
  - Improved the store linking flow

- **TikTok**:
  - Added a retry when fetching data returns an internal error to prevent synchronization from failing immediately

- **Email**:
  - Changed the email title and sender name to X-Store

- **Product**:
  - Added controls for determining whether products can be modified

## Bug Fixes

- **Stock Card**:
  - Fixed timeout issues caused by a large number of documents

- **Sync Quantity**:
  - Fixed automatic quantity synchronization logic
  - Fixed some quantity updates not being applied
