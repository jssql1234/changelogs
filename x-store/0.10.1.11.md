This release adds new features in Post Order, Customize Settings, Payment and Stock Pick, along with several order and product updates and bug fix.

<!-- truncate -->

## Features

- **Post Order**:
  - Added terminate Post Order process feature

- **Customize Settings**:
  - Added AWB customization for printing with picking lists

- **Payment**:
  - Added subtotals for each order or date when payments are grouped by order or date

- **Stock Pick**:
  - Added support for scanning barcodes with a camera

## Updates

- **Post Order**:
  - Used `TRANSACTION_UPDATED_AT` to determine the range of orders to post

- **Order**:
  - Updated Shopify transaction handling
  - Improved AWB printing error messages

- **Product**:
  - Removed the subscription to the Lazada product deletion webhook

## Bug Fixes

- **Order**:
  - Added handling for TikTok sale prices with null values
