Fixed issues with Post Order, Shopee transactions, and Customize PDF previews; added a new TikTok fee; and enhanced product error messages

<!-- truncate -->

## Database

- Database upgraded to version **12**

## Updates

- **Post Order**:
  - Same-day refunds now create a CN document for Shopee adjustments instead of being posted as a net amount
  - Enhanced cancel document validation
  - Added a red dot to the View Failed Results button

- **Order**:
  - Added the new TikTok Seller Funded User Spoint Service Fee
  - Increased the Sync Order range to one year and limited each sync to 15 days

- **Product**:
  - Enhanced error messages

- **Notify Bot**:
  - Removed Notify Bot

## Bug Fixes

- **Post Order**:
  - Fixed null panic
  - Fixed item unit price calculation before order settlement
  - Added a check for unapplied amounts before updating refund documents

- **Order**:
  - Fixed Shopee transactions total condition validation
  - Added support for Shopee transactions B1F1 cases

- **Customize**:
  - Fixed blurry PDF previews
