This release improves synchronization performance and transaction consistency, and fixes user, dashboard, and invoice posting issues.

<!-- truncate -->

## Updates

- **Transactions**:
  - Standardized transaction item descriptions and limited them to 500 characters

- **Shopify**:
  - Updated transaction insertion to use the earliest transaction date

- **Synchronization**:
  - Increased the Lazada, TikTok, and Shopee product and order worker counts from 20 to 50
  - Stopped processing the time-based escrow list after the required result was found

## Bug Fixes

- **User**:
  - Fixed multiple users being created with the same email address

- **Dashboard**:
  - Fixed the Top Selling Products and Top Returned Products queries

- **Post Order**:
  - Fixed invoice posting failures when payments were received on different dates
