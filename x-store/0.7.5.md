This release adds synchronization progress and retry controls, and fixes response, item name, and discounted price processing.

<!-- truncate -->

## Features

- **Synchronization**:
  - Updated the interface to display synchronization progress
  - Added an option to retry failed items

## Bug Fixes

- **Synchronization**:
  - Fixed platform responses not being inserted

- **Order**:
  - Fixed item names being inserted as empty strings
  - Fixed discounts being deducted twice from discounted prices
