This release restores listing copying, refreshes the Boost Product empty state, adds clearer failure messages for store linking and database upgrades, and updates Shopify transaction logic. It also fixes product toolbar shortcuts, Shopee image previews, store warning validation, payment method retrieval, and sync status refreshes.

<!-- truncate -->

## Updates

- **Product**:
  - Updated the empty state on the Boost Product page to use the No Result image.
  - Restored the copy listing feature.

- **Store**:
  - Added a clearer error message when store linking fails.

- **Company**:
  - Added a clearer log message when a database upgrade fails.

- **Payment**:
  - Updated the Shopify transaction logic.

## Bug Fixes

- **Product**:
  - Disabled keyboard shortcuts for unused toolbar actions.
  - Fixed an issue with Shopee product image previews.

- **Store**:
  - Fixed the warning validation for missing store items.
  - Fixed an issue that canceled the request when fetching payment methods.

- **Sync**:
  - Fixed an issue where refreshing the sync status sometimes returned an incorrect status.
