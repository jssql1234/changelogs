Gantt chart improvements, enhanced administration controls, employee selection fixes, and improved form handling.

<!-- truncate -->

## Updates

- **Platform**:
  - Upgraded Flutter to version 3.47.7.

- **Gantt Chart**:
  - Updated the Gantt chart API endpoint.
  - Improved locale support and dark mode styling.

- **Creation**:
  - Added a form-dirty exit dialog to warn users before leaving an edited form.
  - Project, job, and task codes are now displayed when the description is null.

- **Dashboard**
  - Dialogs can now be permanently dismissed.

---

## Bug Fixes

- Added an administrator check to the manager assignment view.
- Removed Edit, Approve, and Finalize buttons from non-administrator views.
- Fixed the previous owner being restored as the primary administrator after ownership transfer.
- Fixed employee selection so selecting a new employee replaces the oldest selection when the selection limit is reached.
- Fixed disabled Employee Cards not displaying their dulled colors.
