Database upgrade, improved serial number selection, automatic weighing scale exports, and fixes for checkout, metadata sync, and e-invoice voiding. (*905*)

<!-- truncate -->

## Database

- POS database upgraded to version **2**, with a new index for sales item serial numbers.

## Updates

- **Serial Numbers**:
  - Show available serial numbers based on the terminal and item code.
  - Allow cashiers to select more serial numbers than the quantity initially entered.
  - Preserve serial numbers when copying a bill with original prices and when a sale is voided.

- **Weighing Scales**:
  - Added automatic item export after metadata sync when export settings are configured.
  - Refined export field configuration and added UOM as a mapping source.
  - Removed Weight Unit Code and Barcode Type mapping sources and revised the available export fields.

- **E-Invoice Requests**:
  - Check the e-invoice request status before voiding a sale and block voiding when the request is valid.
  - Delete pending e-invoice requests when completing a sales void.

- **Interface**:
  - Adjusted default checkout and transaction grids.
  - Display payment method shortcut keys in payment method settings.

## Bug Fixes

- **Checkout & Promotions**:
  - Updated reference prices and promotion original prices when checking or manually changing item prices.
  - Disabled quantity editing for promotion headers.
  - Treat negative flat tax rates as zero.
  - Validate bill discount formatting.

- **Metadata Sync & Access Rights**:
  - Reload user access rights and refresh the promotion list after metadata sync.
  - Refresh checkout quantity formatting after metadata sync.
  - Fixed an error when syncing metadata from the login screen.
  - Fixed logout shortcuts unnecessarily prompting for authorization.

- **Payments & Counter Management**:
  - Corrected rounding in multiple-payment calculations and closing summaries.
  - Fixed a refund document number format query.

- **Dates & SQL Posting**:
  - Corrected bill and held bill time display.
  - Restored missing timestamps in the SQL Posting screen.

- **Weighing Scales**:
  - Corrected quantity formatting for live scale readings.

- **Database**:
  - Use a separate database connection when executing a script against a database other than the active database.
